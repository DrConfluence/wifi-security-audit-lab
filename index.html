Authorization boundary: Network visibility is not authorization. Only explicitly approved networks are treated as in-scope.

CAPABILITIES

What the lab demonstrates

Passive discovery

Collects Wi-Fi metadata through Termux:API without attempting authentication.

Security classification

Classifies observed capabilities as WPA3, WPA2, WPA, WEP, OPEN, or UNKNOWN.

Authorization matching

Separates observed networks from the operator-maintained authorized scope.

Evidence preservation

Produces structured CSV and JSON records with scan IDs and timestamps.

Automated validation

Regression tests protect assessment logic against accidental changes.

Operational discipline

Real observations and authorization records are excluded from the public repository.

WORKFLOW

Assessment methodology

AUTHORIZATION → SCOPE → DISCOVERY → CLASSIFY → VERIFY → EVIDENCE → REPORT

The workflow intentionally stops at the authorization boundary. Active testing is performed only when the written scope explicitly permits it.

REAL-WORLD STANDARD

Safe operation is part of the skill

A strong assessment is not measured by how many networks can be marked "authorized." It is measured by whether the assessor can establish scope, preserve evidence, recognize boundaries, and stop when authorization does not exist.
