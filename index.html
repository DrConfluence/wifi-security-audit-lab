06 // PLATFORM & CAPABILITY BOUNDARIES

⚠ CURRENT ANDROID CONDITION

Android/Termux can restrict low-level networking interfaces. During testing, ip route, ip neigh and some /proc/net interfaces returned permission errors.

Termux:API Wi-Fi scanning also requires Android Location to be enabled. When unavailable, the project records the limitation instead of inventing results.
